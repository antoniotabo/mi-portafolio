## 🌐 Descripción General

Este proyecto aloja el código fuente de mi portafolio profesional en línea. El objetivo de este desarrollo fue crear una identidad digital rápida, accesible y estéticamente moderna ("Dark Mode Engineering") que sirva como punto central para presentar mis proyectos de Ingeniería de Sistemas.

El sitio fue construido desde cero (Vanilla) para garantizar un rendimiento óptimo (Lighthouse Score 100%) y demostrar un dominio sólido de los estándares web actuales sin la sobrecarga de frameworks innecesarios.

## 🎨 Características de Ingeniería Frontend

Este no es solo un sitio estático; es una implementación técnica de diseño moderno:

* **Arquitectura CSS Modular:** Uso extensivo de **CSS Variables (`:root`)** para la gestión centralizada de la paleta de colores y tipografía, facilitando el mantenimiento y la escalabilidad.
* **Diseño Responsivo (Mobile-First):** Maquetación fluida utilizando **CSS Grid** y **Flexbox** para adaptarse a cualquier dispositivo, desde móviles hasta pantallas 4K.
* **Estilo "Glassmorphism":** Implementación de efectos de desenfoque (`backdrop-filter`) en la navegación para una interfaz moderna y profunda.
* **Semántica HTML5:** Uso estricto de etiquetas semánticas (`<header>`, `<nav>`, `<section>`, `<article>`) para maximizar el SEO y la accesibilidad.
* **Optimización de Recursos:** Uso de iconos SVG ligeros (Phosphor Icons) y fuentes optimizadas para tiempos de carga mínimos.
